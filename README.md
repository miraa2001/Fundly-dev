# Fundly

Fundly is a calm expense logging app built with React, Vite, Tailwind CSS, React Router, and Supabase.

## Local setup

1. Copy `.env.example` to `.env`
2. Add your Supabase URL and anon key
3. Run `npm install`
4. Run `npm run dev`

## Scope

Fundly intentionally uses only:

- `profiles`
- `categories`
- `expenses`
